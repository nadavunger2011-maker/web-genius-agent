# ✅ Checklist לפני השקת חנות / אתר

---

## 🔧 טכני

### ביצועים
- [ ] PageSpeed Mobile > 70 (Shopify) / > 80 (WordPress מותאם)
- [ ] LCP < 2.5 שניות
- [ ] CLS < 0.1
- [ ] תמונות ב-WebP, compressed
- [ ] Lazy loading על תמונות שלא בfold הראשון

### SEO בסיסי
- [ ] Title tag לכל דף (50-60 תווים)
- [ ] Meta description לכל דף (150-160 תווים)
- [ ] H1 אחד בכל דף
- [ ] Sitemap.xml קיים ומוגש ב-Search Console
- [ ] robots.txt נכון (לא חוסם דפים חשובים)
- [ ] SSL פעיל (https)
- [ ] Canonical tags על דפים עם duplicate content

### Tracking
- [ ] GA4 מותקן ומאמת ב-DebugView
- [ ] GTM Container פורסם
- [ ] Purchase event עובד (בדוק עם הזמנת טסט)
- [ ] Transaction ID מגיע
- [ ] Value נכון (לא כפול / חלוקה בעשר)
- [ ] Google Ads Conversion מחובר
- [ ] Meta Pixel עובד (Pixel Helper)

---

## 🛒 חנות (Shopify / WooCommerce)

### מוצרים
- [ ] כל מוצר עם תמונה איכותית (מינימום 800×800px)
- [ ] תיאורים ב-200+ מילים עם תועלות
- [ ] מחירים נכונים (כולל מע"מ אם רלוונטי)
- [ ] Variants מוגדרים נכון (Size, Color)
- [ ] מלאי מוגדר

### צ'קאאוט
- [ ] Guest Checkout פעיל
- [ ] אפשרויות משלוח נכונות ובמחירים נכונים
- [ ] אפשרויות תשלום: כרטיס אשראי, Apple Pay, PayPal
- [ ] דף תודה / Order Confirmation עם tracking
- [ ] אימייל אישור הזמנה יוצא

### מדיניות
- [ ] דף "מדיניות החזרה" קיים ומוצג בfooter
- [ ] דף "משלוח ומשלוח" קיים
- [ ] Privacy Policy קיים (חובה!)
- [ ] Terms of Service קיים

---

## 🎨 עיצוב ו-UX

- [ ] Favicon מוגדר
- [ ] 404 page מעוצבת עם חזרה לאתר
- [ ] Mobile נראה מעולה (בדוק ב-3 מכשירים שונים)
- [ ] כל הקישורים עובדים (בדוק עם Broken Link Checker)
- [ ] תמונות עם Alt text
- [ ] CTAs ברורים בכל דף חשוב
- [ ] Trust badges מוצגים בדף הבית ובצ'קאאוט

---

## 📧 אימייל

- [ ] Welcome email יוצא אחרי רישום
- [ ] Abandoned cart flow מוגדר (Klaviyo / Mailchimp)
- [ ] Order confirmation email
- [ ] Shipping confirmation email
- [ ] SPF / DKIM מוגדר לדומיין שלך

---

## 🔒 אבטחה וחוקיות

- [ ] Cookie consent banner (GDPR / ישראל)
- [ ] Consent Mode v2 מוגדר ב-GTM
- [ ] Privacy Policy מעודכן עם כל הכלים שמשתמשים בהם
- [ ] Backup מוגדר (WordPress: UpdraftPlus / Shopify: כלול אוטומטית)
