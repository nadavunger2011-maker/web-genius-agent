# Template: דף מוצר ממיר

## מבנה Above the Fold (מה רואים בלי לגלול)

כל הערכים המספריים (מטבע, סף משלוח חינם, ימי החזרה, דירוג) מגיעים מ-`config.json`:

```
┌───────────────────────────────────────────────────────────────┐
│  [תמונה ראשית]    │  [H1: שם מוצר]                            │
│                   │  ⭐⭐⭐⭐⭐ ({{ config.socialProof.reviewCount }} ביקורות) │
│  [gallery טאמבס]  │                                            │
│                   │  ~~{{ config.commerce.currencySymbol }}[מחיר מקורי]~~  {{ config.commerce.currencySymbol }}[מחיר]  │
│                   │  (חסכון [סכום] - [%])                     │
│                   │                                            │
│                   │  [בחר גודל] [בחר צבע]                    │
│                   │                                            │
│                   │  [🛒 הוסף לסל] ← בולט                    │
│                   │                                            │
│                   │  🚚 משלוח חינם מ-{{ config.commerce.currencySymbol }}{{ config.commerce.freeShippingThreshold }} │
│                   │  🔄 החזרה ב-{{ config.commerce.returnPolicyDays }} יום │
│                   │  🔒 תשלום מאובטח                           │
└───────────────────────────────────────────────────────────────┘
```

## Copywriting לדף מוצר

### H1 — נוסחה
`[שם מוצר] — [תועלת עיקרית בקצרה]`
דוגמה: "{{ config.sampleProduct.name }} — 50 ק"מ ראשונים בלי כאבי ברכיים"

### Short Description Bullets
```
✓ [תוצאה ספציפית] — [איך/למה]
✓ [פתרון לכאב ידוע] — [מה שונה כאן]
✓ [ערבות / ביטחון] — [הסרת סיכון]
```

### FAQ — שאלות שמונעות קנייה
1. "כמה זמן לוקח המשלוח?"
2. "מה אם זה לא מתאים לי?"
3. "האם זה אמיתי / מקורי?"
4. "איך אדע מה הגודל שלי?"

## Urgency / Scarcity (רק כשאמיתי!)

```html
<!-- רק אם באמת נשארו מעט -->
<p class="stock-warning">⚠️ נשארו רק {{ inventory_quantity }} במלאי</p>

<!-- רק אם יש deadline אמיתי — שעת קאט-אוף מ-config.json → commerce.orderCutoffTime -->
<p class="delivery-promise">
  הזמן עד {{ config.commerce.orderCutoffTime }} → משלוח היום 📦
</p>
```

**אזהרה:** Fake urgency הורסת אמון. אל תשתמש בה אם היא לא אמיתית.
