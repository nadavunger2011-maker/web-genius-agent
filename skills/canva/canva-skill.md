## נכסים שכדאי ליצור בקאנבה לכל חנות

### 1. Hero Banner לעמוד הבית
```
גודל: 1920×800px (desktop) + 800×1000px (mobile)
מה לכלול:
- תמונת מוצר/מותג + רקע נקי
- כותרת ראשית (40-60px, bold)
- כותרת משנה (20-24px)
- כפתור CTA (צבע מנוגד לרקע)
- לא יותר מ-3 אלמנטים טקסט
```

### 2. Product Image Overlays
```
מה להוסיף על תמונות מוצר:
- "בסט-סלר" badge
- "משלוח חינם" ribbon
- "חדש" / "מבצע" label
- מחיר מקורי מחוק + מחיר חדש
גודל: 1:1 (800×800px) לשופיפיי
```

### 3. Trust Badges Strip
```
רצועה אופקית עם אייקונים:
🔒 תשלום מאובטח | 🚚 משלוח חינם מ-X₪ | 🔄 החזרה ב-30 יום | ⭐ 4.9/5 (2,341 ביקורות)
גודל: 1200×80px
```

### 4. Email Header
```
גודל: 600×200px
כולל: לוגו + תמונה + כותרת פשוטה
רקע: צבע מותג או לבן
```

## עקרונות עיצוב לאיקומרס

### היררכיה ויזואלית
```
גדול = חשוב יותר
כהה = חשוב יותר  
ממוקם למעלה/מרכז = חשוב יותר
```

### Color Psychology קצר
- **כחול** → אמינות, ביטחון (בנקים, ביטוח)
- **ירוק** → בריאות, טבע, "go" / אישור
- **אדום** → דחיפות, מבצע, warning
- **כתום** → CTA חזק, אנרגיה (Amazon משתמשת)
- **שחור** → פרמיום, לוקסוס
- **לבן** → נקיון, רווח, מינימליזם

### Typography עבור אי-קומרס
- כותרות: Sans-serif bold (Montserrat, Inter, Poppins)
- גוף: Readable sans-serif (16px+ מינימום)
- לעברית: Rubik, Heebo, Assistant (ב-Google Fonts)

## Workflow ב-Canva לחנות

### הגדרה ראשונית (פעם אחת)
1. **Brand Kit** — צבעי המותג, פונטים, לוגו
2. **Templates** — צור תבנית לכל סוג נכס ושמור
3. **Folders** — "Hero Banners", "Product Badges", "Email", "Social"

### יצירת נכס חדש
1. פתח template קיים → Duplicate
2. החלף תמונה / טקסט
3. Download: PNG לתמונות, JPG לבאנרים (80% quality)
4. WebP אם הפלטפורמה תומכת (חצי גודל, אותה איכות)
