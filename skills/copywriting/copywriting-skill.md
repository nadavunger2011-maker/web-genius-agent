# Skill: Copywriting — כתיבה שיווקית ממירה

## מתי להשתמש
כתיבת דפי מוצר, landing pages, ads, emails, CTAs, כותרות.

---

## עקרון הזהב
**אל תמכור מוצר. מכור את השינוי בחיים של הקונה.**

לא: "נעליים בעלות סוליה ייחודית"
כן: "עמוד על הרגליים 12 שעות בלי שגבך יצעק עליך עד הלילה"

---

## Frameworks עיקריים

### PAS — Problem, Agitate, Solution
```
Problem:  יש לך חנות שופיפיי אבל אתה לא מוכר?
Agitate:  כל יום שעובר בלי מכירות זה כסף שהמתחרה שלך לוקח.
          הפרסום עולה, ה-ROAS יורד, ואתה לא מבין למה.
Solution: [המוצר/שירות שלך] — [איך הוא פותר את הבעיה]
```

### AIDA — Attention, Interest, Desire, Action
```
Attention: כותרת שמושכת עין (שאלה, מספר, הבטחה)
Interest:  למה זה רלוונטי אליו ספציפית
Desire:    ויזואליזציה של ה"אחרי"
Action:    CTA ברור עם תועלת (לא "לחץ כאן")
```

### Before/After/Bridge
```
Before: איפה הלקוח עכשיו (הכאב)
After:  איפה הוא רוצה להיות (החלום)
Bridge: המוצר שלך = הגשר ביניהם
```

## כתיבת כותרות (Headlines)

### נוסחאות שעובדות
```
"איך [להשיג תוצאה] ב[זמן/מחיר/מאמץ] בלי [הפחד הגדול]"
"[מספר] דרכים ל[תוצאה] — גם אם [מכשול נפוץ]"
"[תוצאה] תוך [זמן] — [ערבות]"
"הפסק [כאב] לנצח עם [פתרון]"
```

### דוגמאות
- ❌ "מוצר איכותי לטיפוח עור"
- ✅ "עור נקי ב-7 ימים — או שאנחנו מחזירים לך את הכסף"

---

## Bullet Points — תועלות, לא פיצ'רים

### מבנה bullet point ממיר
`[פיצ'ר] — [מה זה אומר לך] — [למה זה חשוב]`

```
❌ "סוליה ייחודית בטכנולוגיה מתקדמת"
✅ "סוליה אורתופדית מוקשחת → גבך נשאר ישר גם אחרי 10 שעות עמידה"

❌ "חומרים טבעיים בלבד"
✅ "ללא ריח כימי חריף — בטוח לשימוש ליד ילדים ובעלי חיים"
```

## CTAs — מה לכתוב על הכפתור

### עקרון: CTA = תועלת, לא פעולה
```
❌ "לחץ כאן"
❌ "שלח"
❌ "קנה עכשיו"

✅ "קבל משלוח חינם עד מחר"
✅ "התחל את ה-7 ימים בחינם"
✅ "הבטח את המקום שלי (נשארו 3)"
✅ "אני רוצה [תוצאה]"
```

## כתיבה בעברית — חוקים נוקשים

### אסור לחלוטין
- "אנו מזמינים אתכם לגלות"
- "חווה את החוויה המדהימה"
- "פתרון מוביל ומקצועי"
- "שירות מעולה ללקוחות"
- כל מילה שיכולה לכתוב כל אחד

### מותר ורצוי
- ספציפיות: "חוסך 3 שעות בשבוע" > "חוסך זמן"
- מספרים: "127 לקוחות" > "הרבה לקוחות"
- שמות: "כמו שגלית מ-ראשל"צ עשתה"
- שאלות: "מה היית עושה עם 3 שעות פנויות?"
- עברית ישראלית: "בוא נדבר ישר..."

---

## Social Proof — סדר עוצמה
1. **ביקורת עם תמונה** > ביקורת טקסט
2. **ביקורת עם תוצאה ספציפית** > "מוצר מעולה"
3. **מספר לקוחות** ("3,847 לקוחות מרוצים")
4. **לוגואים** של מותגים / מדיה שכתבו עליך
5. **תעודות / הסמכות**
