# FullBody.co.il — ביקורת אתר (Lovable frontend + Shopify backend)

תאריך: 2026-06-23
מקור: snapshot `.mht` של דף הבית שצולם מ-fullbody.co.il (גישת רשת חוצה חסומה בסביבת העבודה, אין WebFetch/curl ישיר).

## רקע
- האתר נבנה ב-Lovable (React + Tailwind, RTL), עם checkout ומוצרים מחוברים לשופיפיי.
- בעל האתר: נדב אונגר — מפיץ עצמאי מורשה של Herbalife בישראל. ח.פ 200353720, זרחין 1 רעננה.
- בעיה מרכזית של הלקוח: הפיצול בין Lovable (frontend) ל-Shopify (checkout+מוצרים) **שובר אנליטיקס/מדידת המרות** — צריך איחוד הפלטפורמות (להעביר את כל הדיזיין לתוך Shopify).

## מבנה דף הבית (כפי שנצפה)
1. Header: לוגו, תפריט (ראשי / מוצרים / מאמרים / צור קשר), חיפוש, עגלת קניות, באנר top "משלוח חינם מעל ₪299 · ליווי אישי · רכישה מאובטחת".
2. Hero: סליידר 2 שקופיות, H1 "התחילו את השינוי שלכם היום", 4 USP icons (מוצרים מקוריים / משלוח מהיר / תשלום מאובטח / ייעוץ מקצועי).
3. קטלוג עם פילטרים: קטגוריות (הכל/אבקות חלבון/ספורט ואנרגיה/חטיפי חלבון/ויטמינים/תה ומשקאות/עיכול והידרציה), פילטר מתקדם (סוג חלבון, מהירות ספיגה, מטרה, טעם, טווח מחיר).
4. גריד מוצרים (~20+ פריטים: Formula 1 בטעמים, PDM, H24, אלוורה, Niteworks, חטיפים, ויטמינים, תה צמחי וכו').
5. "למה FullBody" — 3 USP (רכיבים טבעיים / תזונת ספורט / שליטה במשקל).
6. בלוקי סושיאל פרוף כפולים — טסטימוניאלים + "הצלחה במספרים" (סטטיסטיקות) + "הצלחה בכל קטגוריה" (חופף חלקית עם הבלוק הראשון).
7. דיסקליימרים רגולטוריים (Herbalife-compliant) — תוצאות לא טיפוסיות, לא לאבחון/טיפול, התייעצות עם רופא.
8. בלוג (3 פוסטים מוצגים).
9. CTA "מוכנים להתחיל?" + יצירת קשר.
10. Footer: trust badges (SSL, משלוח, מותגים, תשלום), ניווט, מדיניות משפטית, פרטי קשר, דיסקליימרים מלאים.
11. כפתור WhatsApp צף.

## ממצאים — בעיות לתיקון

### SEO / טכני
- `<html lang="en">` על אתר עברי-RTL מלא — באג; צריך `lang="he"`.
- אין JSON-LD (`Product`, `Organization`, `BreadcrumbList`) בכלל — מפסיד Rich Results בגוגל (כוכבים/מחיר/מלאי).
- כתובות מוצר בפורמט `/product/<slug>` (לא `/products/` הסטנדרטי של שופיפיי) — מצביע על frontend מותאם, שבמעבר לשופיפיי native צריך redirect map כדי לא לאבד SEO equity.
- `og:image` קיים, מטא תיאור תקין, canonical תקין.

### CRO / UX
- **אין מחירים על כרטיסי המוצר בגריד** — רק "לפרטים נוספים", בלי ₪ ובלי Add-to-cart מהליסטינג. חסם המרה — לקוח צריך קליק נוסף בלי לדעת מחיר.
- כפילות טסטימוניאלים בין שני בלוקי social-proof (למשל "הדר כהן" מופיעה פעמיים) — מרגיש חזרתי בדף ארוך.
- פילטרים מתקדמים (סוג חלבון/ספיגה/מטרה/טעם/טווח מחיר) — חוויה טובה אם יש מספיק SKUs, אחרת overkill.

### חוזקות לשמר
- Trust badges חזקים: SSL, אישור משרד הבריאות, ספק הוועד האולימפי, אזכורים בתקשורת (וואלה/כלכליסט/גלובס/ישראל היום).
- כשרות מהדרין כבידול תחרותי בשוק הישראלי.
- Disclaimers משפטיים מקיפים ותקניים (Herbalife/FTC-style) — לשמר בקפדנות במעבר לפלטפורמה חדשה (חיוני רגולטורית).
- מיקוד persona ברור: שליטה במשקל / תזונת ספורט H24 / חיוניות יומית.

## משימה פתוחה: מיגרציה ל-Shopify מאוחד
המטרה: לבטל את הפיצול Lovable+Shopify ולהעביר את כל העיצוב (theme) לתוך Shopify Liquid, עם המוצרים/checkout שכבר קיימים שם, כדי לאחד אנליטיקס (GA4/Meta Pixel/GTM) על פלטפורמה אחת.

נקודות שצריך להחליט לפני בנייה:
1. גישה לחנות Shopify בפועל (Admin API מחובר) כדי למשוך מוצרים/קולקציות אמיתיים ולבנות לפיהם.
2. בסיס Theme: לבנות Liquid theme מאפס שמשכפל את העיצוב, או להתחיל מ-theme קיים (Dawn) ולהתאים אליו את הסקשנים.
3. דפים/פיצ'רים שדורשים מימוש Liquid+JS: hero slider, פילטור מוצרים (Shopify search/filter API או Liquid+JS custom), בלוקי social-proof/סטטיסטיקות, בלוג (Shopify Blog), WhatsApp widget.
4. שמירה על redirect map מ-`/product/<slug>` הישנים ל-`/products/<handle>` של שופיפיי כדי לא לאבד SEO.
5. העברת/שכפול הדיסקליימרים הרגולטוריים בדיוק (קריטי — דרישות Herbalife).
